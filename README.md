# VHS Near Me

Independent directory of places that digitize VHS, VHS-C, Hi8, Video8, MiniDV, 8mm and Super 8 film, photos, slides, and negatives.

The site is static HTML and CSS. GitHub Pages serves it from the repository root. The public URL is [https://dmlehinger-web.github.io/vhsnearme/](https://dmlehinger-web.github.io/vhsnearme/), so every internal link is under `/vhsnearme/`.

Two halves:

- **City pages** for local drop-off and pickup. Dallas–Fort Worth is the first one, including Flower Mound, Lewisville, and Denton.
- **A mail-in comparison** of companies that publish a price and will take a box.

Prices are copied from each business’s own site and linked. If a site does not print a number, the listing says “Call for pricing.” The directory does not invent businesses, reviews, or prices.

`sitemap.xml` and `robots.txt` list the same pages. There is no analytics tag and no third-party font.

## How the files fit together

- `data/cities/*.json` — one file per city. Files whose names start with `_` are templates and are not published.
- `data/services.json` — mail-in companies.
- `data/formats/*.json` — format guides.
- `data/affiliates.json` — ScanMyPhotos, Legacybox, and iMemories. Affiliate IDs are empty, so those visit links are ordinary URLs. Fill `affiliate_id` and `affiliate_param` together when a public publisher ID exists. Do not commit secrets. `.gitignore` ignores `.env` and `.env.*`.
- `data/home.json`, `data/about.json`, `data/snippets.json`, `data/site.json` — shared copy and the `/vhsnearme` base path.
- `templates/page.html` — the document shell (header, footer, meta tags).
- `css/styles.css` — the only stylesheet.
- `scripts/build.py` — reads the data and writes HTML, `sitemap.xml`, `robots.txt`, and `og.png`.

Generated HTML starts with `Generated by scripts/build.py`. Edit the data, then rebuild. The next build overwrites hand-edits to those HTML files.

## Build and preview

```bash
python3 scripts/build.py
```

Python 3.9+ is enough. There are no packages to install.

Local preview has to include the `/vhsnearme/` prefix, because that is how the links are written:

```bash
python3 scripts/build.py
mkdir -p /tmp/vhs-preview
ln -sfn "$PWD" /tmp/vhs-preview/vhsnearme
python3 -m http.server 8080 --directory /tmp/vhs-preview
```

Open `http://localhost:8080/vhsnearme/`.

## Add a city

The exact recipe, including every JSON field, is in [CONTRIBUTING.md](CONTRIBUTING.md). Short version:

1. Copy `data/cities/_template.json` to `data/cities/<slug>.json`.
2. Replace the placeholders with facts from each business’s own website. Use “Call for pricing” when they do not publish a number.
3. Run `python3 scripts/build.py`.
4. Commit the JSON file and the generated HTML, sitemap, and robots file.

That rebuild refreshes the city page, the cities index, the homepage city list, `sitemap.xml`, and `robots.txt`.
